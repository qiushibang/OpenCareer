# 公网 Career 安全收敛

## 目标与边界

封堵审计发现的共享身份入口、共享技能写入、用户指定程序和模型地址访问内网。
复用原权限引擎、用户身份与 PostgreSQL 强制行隔离，不构建新的 Agent 框架。
安全由服务端能力约束保证，不由提示词分类器决定。不能承诺所有提示词攻击消失。

## 策略

1. 正式编排删除 18080 端口映射与共享 Token 代理；Authing 配置时 HTTP/WebSocket
   只接受应用会话 Cookie，不再回退旧 Header/协议 Token。桌面本地身份保持原行为。
2. Alpha HTTP 使用方法与路径显式白名单，未知路由默认拒绝。技能只读，禁止上传、
   更新、移动、删除和任意工作区查询；通用工作区 Artifact 接口关闭。Career 私有
   原件、面试 Artifact、自己的对话与确认操作仍通过现有租户身份访问。
3. 云端禁用 Aiden/Ollama/Bedrock/Vertex 和未知模型 Provider。允许的 Provider 只能
   使用对应静态官方 HTTPS 地址及明确列出的国内端点，禁止任意代理、用户信息、
   非标准端口、查询参数与片段。保存、验证与历史配置加载均校验；不读取服务器
   桌面凭据或自动发现本地程序。
4. 从云端 Agent 工具白名单删除任意 URL 读取；查询岗位库、粘贴 JD 和面试不受影响。
   所有 get_engine 构建路径都裁剪工具能力，而非仅 WebSocket 接入时裁剪。
5. HTTP 上传设置请求体大小上限；按认证用户限制请求与并发连接，限制全局连接数。
   异常拒绝仅记录分类原因，不记录身份、简历、提示词、凭据。关键写入维持人工确认。
6. 容器使用非 root、禁止提权、移除 Linux 能力；不挂宿主目录或 Docker socket。
  保留现有业务数据卷和数据库部署，不删除历史技能或数据。

## 2026-09-17 用户确认补充：回复图片隐私

云端 Alpha 的 Markdown 回复不生成图片元素，也不保留图片源地址，改为显示
“图片未自动加载”。包括行内与引用式 Markdown 图片；不提供一键自动恢复。
普通链接保持用户手动打开及 noreferrer，网站正常界面资源不受影响。
桌面非 Alpha 模式维持原图片显示。公开验收边界为实际回复渲染组件的这三种
界面行为；云端与桌面测试按真实构建模式分别运行，不模拟内部模块。

## 验收与发布

先写失败回归，再逐项修复：HTTP/API 写入口、Cookie-only 身份、模型保存/验证/
历史配置、非 WebSocket 引擎工具范围、已有自动审批与租户隔离回归。所有测试
不默认访问公网，不执行危险程序或删除生产数据。发布前新建 PostgreSQL、配置、
前端、数据卷和旧镜像恢复点；发布后验证域名登录、旧入口关闭、线上能力策略、
安全拒绝和容器健康。完整真人双账号体验与第三方渗透不冒充已完成验收。
