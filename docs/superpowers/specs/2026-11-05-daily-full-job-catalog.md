# 每日全量岗位目录

每天 Asia/Shanghai 04:00 开始一个独立代次，默认无随机延迟。当天的采集库从空库开始，不从昨天的岗位、分页或来源成功状态取数据；同一代次内允许断点续跑和失败重试。下一天由独立监督进程终止旧代次工作并另建空库，慢来源不延迟04:00的新任务；不把跨日未完成代次充作当天结果。

复用注册官方来源 Adapter、LocalJobSync 和既有分页完整性验证。全部注册来源完成且岗位观测属于本代次才发布；任何来源失败/未完成则不替换公共清单，显式报告未完成来源。这里的“所有”是项目已注册公开官方来源，不代表覆盖官网未开放的接口。没有绕过平台限制，也不把失败说成零岗位。

全量当前集合与历史账本分离。历史账本只含公共岗位与变化，不含用户数据；完整代次比较得出新增、内容更新、下线与重新开放，首次建立基线属于补录。保持稳定来源+官网岗位标识；全量发布只含当前岗位。用户的收藏、申请、面经独立保留，缺失岗位退出在招列表，不删除关联记录。

公共目录第二版提供全量模式、代次开始/完成时间、来源完整性信息以及各当前岗位最近90天的新增/更新/重开/补录事件。使用不可变压缩文件与原子清单替换，失败保留上一版。客户端继续兼容第一版；第二版中缺失岗位立即退出在招集合，服务端变化时间原样导入，避免新用户第一次下载丢失“昨天新增”。查询和订阅继续使用既有 JobCatalog/MCP 工具，不改 Agent Loop。

04:00 指开始时间，不承诺此时已完成。最近确认时间是实际官网观测时间，不是写文件或下载的时间。下线历史不刷新为今天。客户端点击同步只下载最新完整服务端目录，不触发每个用户独立全网抓取。

提供与网站无关的独立采集入口和专用容器编排；数据目录、锁、目录文件只属于采集任务，不连接网站生产数据库。当前仅本地实现/验证；线上后端迁移期间不更改网站、隧道、生产数据库或公共文件。最终公开目录实际发布与从公网空库下载需要另行在确认的采集主机执行。

验收：四点/时区/重启/跨日；两天均实际调用所有来源；失败不发布；全量缺失与重开；身份和备注保留；首次下载保留上游新增日期；自然语言工具日期条件仍可筛选；压缩摘要/非法事件拒绝；无私有字段导出；真实来源核验与默认公网验收分别记录。

实现中的关键回归：旧检查点在内容未变时仅更新列 observed_at，未更新 snapshot_json.observed_at，最终入库读到旧副本。现在写入同步更新，读取旧检查点也只使用其已有权威观测列（不使用当前时间补写）。完成时间保留亚秒精度，避免把真实新岗位误判为完成时间之后的补录。

客户端第二版整轮先下载校验，全部来源同一个事务提交；任一下载或写入失败，保留上一整代数据。服务端每天监督子进程，到次日04:00停止旧代次剩余工作并启动新代次；失败来源至少退避15分钟，分页未完成按短间隔继续。

兼容发布使用独立 `/public/jobs/v2/`，旧v1目录和线上程序保持原状。新客户端优先v2；仅新目录未安装时显式回退v1，并报告实际协议与回退状态，每次同步重新检查v2。数据损坏和访问错误不触发回退。只有成功读取v2且其来源属于真实完整当日扫描，才通过最新目录验收。
