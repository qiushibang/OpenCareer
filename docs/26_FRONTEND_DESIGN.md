# OpenCareer 前端视觉与体验验收（2026-11-04）

本轮按用户确认的“温暖浅色、精致克制”方向优化现有工作台，保持功能和数据接口兼容。只修改本地代码和本地预览，没有部署生产、推送仓库、调用真实模型或重新发送渠道消息。

## 视觉规则

以暖纸色、陶土橙和深灰正文形成层级；对话首页使用编辑式标题，数据页使用更紧凑的工作台排版。统一主标题、控件、圆角、边线、浮层阴影、选中态与键盘焦点。配色由 `surfaces/gui/src/design-system.css` 集中定义，避免引入新的组件库、在线字体和远程图片。

参考 [Webby 官方评审维度](https://www.webbyawards.com/judging-criteria/) 检查结构导航、视觉、功能、交互与整体体验。这是设计自检参照，不代表获得奖项或专业机构认证。

动效只辅助方向与反馈：入口卡片轻微抬升、弹层短距离进入，支持系统“减少动态效果”。表头不使用形成持续层叠上下文的动效，防止筛选菜单被后方表格遮挡。
