# 本地版浏览器、外部服务与文件夹

本地启动器开放会话右侧的「访问权限」。公共网站继续使用独立的受限策略；本功能不需要修改生产配置。

## 使用方式

在对话页点击「显示侧边面板」，展开「访问权限」。浏览器默认启用，可以让助手读取公开网页、填写页面和操作网页控件。浏览器打开的是本机独立窗口，不会读取你日常浏览器已有的登录状态。首次正常安装会安装现有 Playwright 浏览器组件与 Chromium；旧开发环境若使用 `--skip-install`，需要先安装 `.[browser]` 并运行 `python -m playwright install chromium`。

「添加工具或服务」选择已注册的连接器。浏览器无需凭据；其他服务仍需由你连接账号或填写自己的访问凭据，开启入口不代表已取得第三方授权。服务支持的工具可单独开关，对话中的开关只影响当前对话。依赖上游 OpenWorker 云端中转的连接方式不在本地版提供；保留手动配置及服务支持的直接授权连接。第三方账号授权受各平台策略约束。

「添加可访问文件夹」选择或粘贴资料目录，默认只读；只有明确勾选「允许写入」才能修改该目录。路径属于**运行本地服务的电脑**。移除目录会撤销本次对话的授权，其他对话不会自动获得该目录。每个对话另有独立的临时工作区，实际文件保存在数据目录下的 `state/local-workspaces`，重启不会自动清空。

## 权限边界

程序源码、配置、存放密钥的数据目录及它们的上级目录不能授权给助手。文件读取、写入、浏览器上传和截图均检查会话授权范围；符号链接不能越过范围。浏览器拒绝访问回环地址和内网服务，包括重定向后的目标。网页内容只是外部数据，不能授予目录或更改连接配置。

不开放任意命令执行、通用工具进程配置、文件删除或通过 Git 克隆／拉取执行宿主机进程的工具。外部写入与发送继续经过现有审批机制；关闭服务或工具后，当前会话的可用工具随即刷新。此版本不提供公网多人使用本地权限的能力，不要将本地端口转发至公网。

## 验证范围

自动测试覆盖本地与公共策略隔离、目录只读／写入／撤销、重启恢复、越界与符号链接、浏览器工具开关、临时工作区交付物，以及真实 Chromium 的网页读取、点击、输入、上传、截图和内网重定向拦截。浏览器网页和资料使用虚构测试夹具，不调用付费模型，不向第三方发送消息。

第三方真实账号的一键授权、授权后的服务读写，以及模型主动选择这些新工具，需要使用你自己的账号另外验收；模拟测试通过不代表这些平台已实际连接。
