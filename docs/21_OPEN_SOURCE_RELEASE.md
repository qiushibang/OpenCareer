# 开源与本地版发布验收

## 边界

私有维护仓库保留 Git 历史；公开仓库从审查后的源码快照开始，保留 MIT 许可证和
OpenWorker 来源说明。公开前检查源码、构建配置和提交内容，禁止包含生产密钥、
真实简历、用户对话、日志、宣传截图或开发工具状态。

本任务不执行生产部署脚本、不修改生产配置、不重启生产容器、不迁移生产数据库。
现有托管网站与本地数据完全独立；发布源码不会自动触发生产部署。

## 用户已确认的验收接口

- `python3 start_local.py`：首次安装依赖、构建并打开本地网页；再次运行保留数据。
- 浏览器只连接回环地址，无需 Authing，不读取生产数据库或开发者账号配置。
- 用户在界面自行配置模型；密钥不进入前端静态构建产物。
- 外部网页来源和伪造 Host 请求被拒绝；后端直接访问仍需启动令牌。
- 端口占用时退出，不停止现有进程；退出只清理本次子进程，不删除用户数据。

首版支持源码本地网页版。Docker 一键包和签名桌面安装包不在本次已验证交付范围，
完成单独构建与平台验收前不提供“已可用”下载入口。

## 发布门槛

1. 当前源码秘密扫描、隐私路径检查和人工检查通过。
2. 后端和领域测试分别运行，避免同名模块收集冲突；前端测试和类型检查通过。
3. 全新源码副本安装、真实浏览器打开、模型设置、重启持久化和来源防护通过。
4. 私有仓库推送并核对提交；公开候选仓库先私有，检查内容与工作流后再公开。
5. 公开后匿名验证源码访问；生产仅做只读健康核对。

扫描不能证明绝对安全。真实付费模型回答、真人麦克风和 Windows 安装包应分别记录，
未验证的项目不得标为通过。
