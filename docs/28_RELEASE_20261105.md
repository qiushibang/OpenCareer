# 2026-11-05 开源本地版更新

本次更新仅发布源码，不部署托管网站。

- 求职进度表、逐轮面试与面经、Excel 导出；保留原申请进度和备注。
- 区分岗位新增、更新、重新开放与历史补录；持续采集使用公开官方来源。
- 岗位订阅增加飞书扫码连接与简洁的对话引导，用户自然语言描述需求后核对草稿并显式启用。引导入口不自动调用模型或发送消息。
- 本地浏览器与已注册外部服务入口，资料文件夹手动授权、默认只读，独立会话工作区；公共网站继续隔离宿主目录，不开放任意命令。
- 温暖浅色界面、紧凑筛选、日期输入与浮层定位优化；修复本地多窗口轮询限流后岗位列表无法恢复，以及输入框内部重复焦点边框。
