## 从零安装与真实模型复验

2026-11-05 从公开仓库重新克隆，在空数据目录使用 Python 3.12.13 与经官方校验的 Node.js 22.23.4，运行 README 的正常安装命令（未使用 `--skip-install`），全新创建 Python 环境与前端依赖。未配置模型时公共岗位已可同步和浏览，初始会话、渠道和订阅为空。

使用用户授权的测试模型完成自然语言查询及两轮订阅对话；无渠道时正确引导扫码，有本地虚构渠道后成功创建停用草稿，查询和预览条件一致，无启用、运行或发送记录。真实渠道投递仍未在本轮验收。

复验发现并修复：模型在生成完整草稿后再次读取订阅列表，原界面会误用最后一次窄范围示例查询。现在同一轮的草稿条件优先用于订阅确认与雷达跳转，保留全部招聘类型及名称、时间；新增对应调用顺序回归测试。修复前该用例失败，修复后全新环境前端347项通过，2项跳过。

公共目录中的来源确认时间可能明显早于下载时间。程序及模型会标明待核验的历史岗位；本轮没有修改线上采集服务，也不将首次下载当作新增或承诺官网实时在招。
